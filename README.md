# 1Fi Marketplace Super App

A modern, responsive fintech eCommerce and EMI financing platform built for the **1Fi SDE Intern Assignment**.

## 🚀 Features

- **Shop Multi-tab Experience**:
  - **1Fi Marketplace**: Full catalogue with multi-category filters, search, sorting (price, rating, featured).
  - **Top Brands**: Direct brand tie-ups directory placeholder.
  - **Nearby Stores**: Offline retail QR checkout store directory placeholder.
- **Product Details & Configurator**:
  - Color & Memory variant selection.
  - Comprehensive technical specifications breakdown.
  - Multi-image gallery with smooth transitions.
- **Dynamic EMI Calculator & Instant Credit Checkout**:
  - Real-time tenure and interest rate calculation.
  - Pre-approved limit badge and zero down payment options.
  - Interactive confirmation modal with instant approval state.
- **Micro-Interactions & Animations**:
  - Tailwind CSS v4 `@theme` animations with reduced-motion accessibility support.
  - Staggered product cards fade-in, image hover zoom, and button press states.

## 🛠️ Tech Stack

- **React 18**
- **Vite 5**
- **Tailwind CSS v4** (`@tailwindcss/vite`)
- **Lucide Icons**

## 💻 Getting Started

```bash
# Install dependencies
npm install

# Run local development server
npm run dev

# Build for production
npm run build
```
